# UIU Used Textbook Marketplace

A responsive marketplace prototype where UIU students can browse, buy, sell, and manage used textbooks, notes, and lab manuals.

## Demo roles

- Guest: browse, search, and filter listings
- Buyer: wishlist, purchase request, payment choice, and messaging
- Seller: dashboard, listing submission, listing management, and sales history
- Admin: listing approval, category management, and reports

## Payment choices

- Cash on Meet
- bKash
- Nagad

## Run locally

Open this folder in VS Code, then open `index.html` with Live Server. An internet connection is needed for remote listing images.

## Project status

This repository currently contains a frontend-only demonstration build. Dashboard values, users, messages, listings, transactions, and reports are mock data for presentation purposes. A backend and database can be added later in this same repository.
